# Психологический чекап — Telegram-бот и Mini App

Пользователь открывает Mini App из бота и проходит короткие скрининговые опросники. Сразу после этого он видит результаты, а бот присылает отчёт в чат и сохраняет историю.

| Сфера | Опросник | Вопросов | Лицензия |
|---|---|---|---|
| Настроение / депрессия | PHQ-9 | 9 | свободное использование (Pfizer) |
| Тревога | GAD-7 | 7 | свободное использование (Pfizer) |
| Общее благополучие | WHO-5 | 5 | свободное использование (ВОЗ) |
| Стресс | PSS-10 | 10 | бесплатно для некоммерческого/исследовательского использования, для коммерции уточняйте |
| Депрессия (доп.) | Шкала Бека BDI-IA, адаптация Н. В. Тарабриной | 21 | права на шкалы Бека у Pearson; для коммерческого использования нужна лицензия |
| Жизненные ловушки (доп.) | Опросник 11 ловушек, Дж. Янг и Дж. Клоско, пер. Е. Кваши | 110 (11 шкал × 10) | текст из книги «Прочь из замкнутого круга!» (Эксмо, 2019) защищён авторским правом |

Дополнительные тесты (`"optional": true`) по умолчанию не отмечены на экране выбора. «Жизненные ловушки» не являются клиническим скринингом, поэтому не влияют на общий вывод чекапа (`"excludeFromSummary": true`).

Ловушки считаются по 11 подшкалам: вопросы чередуются (1, 12, 23… — покинутость; 2, 13, 24… — недоверие и т. д.), каждая подшкала от 10 до 60. Пороги по книге: 10–19 очень низкий, 20–29 довольно низкий, 30–39 умеренный, 40–49 высокий, 50–60 очень высокий.

## Как устроено

```
webapp/          статическая Mini App (HTML/JS, без сборки)
  tests.json     ← единый источник вопросов, шкал и порогов (читают и Mini App, и бот)
bot/
  main.py        бот на aiogram 3: /start, /history, /delete, приём результатов
  scoring.py     валидация и пересчёт баллов на сервере (клиенту не доверяем)
  db.py          SQLite
```

1. `/start`: бот показывает кнопку «🧠 Пройти чекап» (`KeyboardButton` с `web_app`).
2. Пользователь отвечает на вопросы и видит результаты.
3. Кнопка «Сохранить и отправить в чат» вызывает `Telegram.WebApp.sendData(...)`, и бот получает сырые ответы.
4. Бот пересчитывает баллы, сохраняет их и присылает отчёт.
5. Если в PHQ-9 №9 (мысли о смерти или самоповреждении) ответ не «ни разу», бот и Mini App показывают блок с телефонами помощи. Номера настраиваются в `tests.json` → `crisis`.

## Запуск

1. Создайте бота у [@BotFather](https://t.me/BotFather) и получите токен.
2. Опубликуйте папку `webapp/` на любом HTTPS-хостинге: GitHub Pages, Netlify, Vercel или Cloudflare Pages. Для локальной разработки подойдёт `python -m http.server` в `webapp/` плюс туннель (ngrok или cloudflared).
3. Настройте и запустите бота:

```bash
cp .env.example .env   # впишите BOT_TOKEN и WEBAPP_URL
```

```bash
python -m venv .venv && .venv/bin/pip install -r requirements.txt
```

```bash
.venv/bin/python -m bot.main
```

## Как добавить тест

Добавьте объект в `tests.json` → `tests`: варианты ответа, вопросы (`reverse: true` для обратных пунктов, `crisis: true` для «тревожных») и `scoring.bands` с порогами. Код менять не нужно.

## Ограничения MVP и что дальше

- `sendData` работает, только если Mini App открыта через кнопку обычной клавиатуры. Чтобы открывать её из menu button или inline-кнопки, нужен небольшой HTTP-бэкенд: Mini App отправляет ответы вместе с `initData`, а бэкенд проверяет подпись по токену бота.
- Возможные следующие шаги: напоминание пройти чекап через месяц, график динамики в Mini App, тесты на сон (ISI требует лицензии) и выгорание, выдача контактов психологов.
- **Юридически:** приложение собирает данные о здоровье (в РФ это специальная категория персональных данных по 152-ФЗ). Перед запуском нужны согласие на обработку, политика конфиденциальности и хранение БД на серверах в РФ.
- Это скрининг, а не диагностика. Тексты в приложении это проговаривают; не убирайте эти формулировки.
